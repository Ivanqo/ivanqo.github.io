# Персональный лендинг (Cyberpunk)

Готовая статическая страница **обо мне** (разделы переключаются с красивыми переходами):
- Обо мне
- Портфолио
- Опыт работы
- Контакты

## Структура
- `index.html` — разметка
- `styles.css` — тема (IT / cyberpunk / tech)
- `app.js` — переключение вкладок + анимации + фон (canvas)
- `README.md` — это описание

## Как запустить локально
Достаточно открыть `index.html` в браузере.

### Рекомендуемый способ (чтобы работали все фичи одинаково)
Через простой http-сервер:

```bash
python -m http.server 8080
```

Открой `http://localhost:8080`

## Как выложить на GitHub Pages
1. Создай репозиторий: `ivanqo.github.io`
2. Залей в корень репозитория **все файлы из архива**
3. GitHub → Settings → Pages → Deploy from a branch → `main` и `/(root)`
4. Сайт будет доступен по адресу: `https://ivanqo.github.io`
